# Xpandi Apps Hub

This repository serves the static organization Pages hub for:

https://apps.xpandi.top/

The old Hexo blog content was migrated into WordPress and is archived in the `archive/hexo-blog-20260601` branch. New blog content should live in WordPress at:

https://www.xpandi.top/blog/

## Canonical App URLs

- BOTC Companion: https://apps.xpandi.top/botc-script-editor/
- Value Journal: https://apps.xpandi.top/value-sort/

GitHub Pages serves project sites by repository name under the organization custom domain. This repository owns the `apps.xpandi.top` custom domain; individual app repositories should not define their own `CNAME` unless they move to a dedicated subdomain.

## Convenience Aliases

- `/botc-companion/` redirects to `/botc-script-editor/`
- `/value-journal/` redirects to `/value-sort/`
